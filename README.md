🧮 Task 2A: Scientific Calculator Web Application
Welcome to the Scientific Calculator Web Application — a fully interactive, browser-based calculator built using HTML, CSS, and JavaScript. Developed as part of the SkillCraft Technology Internship, this app supports both basic and scientific operations, with advanced UI features and keyboard input support.

🕹️ About the Project
This calculator enables users to perform a wide range of mathematical operations with precision. From basic arithmetic to scientific functions, the intuitive 2D-styled button interface and keyboard accessibility make it user-friendly across devices.

✨ Key Features
✅ Basic operations: Add, Subtract, Multiply, Divide
📐 Scientific functions: Square root, Power, Basic Trigonometric functions, Logarithms
🎨 UI with 3D button effects for interactive feedback
⌨️ Full keyboard input support for efficient use
⚠️ Error handling (e.g., divide by zero, invalid expressions)
🖥️ Responsive layout for all screen sizes
🌐 100% client-side (no backend/database)
